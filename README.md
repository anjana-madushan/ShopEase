# ShopEase

## 📌 Project Overview  
This project is a **complete end-to-end E-commerce system** developed using a **client-server architecture**. It includes:  

- A **web application** for back-office operations.  
- A **mobile application** for customers.  

The system supports multiple user roles, product and order management, inventory tracking, and vendor management.  

## 🛠️ Tech Stack  
- **Backend:** C# ASP.NET  
- **Database:** MongoDB  
- **Frontend:** React.js  
- **Mobile App:** Java (Android)  

## 🌟 Features  
### 🔹 Web Application (Admin & Vendor Portal)  
- **User Management:** Role-based access control (Admin, Vendor, CSR).  
- **Product Management:** Vendors can add, update, and remove products.  
- **Order Management:** Track orders, update statuses, and manage cancellations.  
- **Inventory Management:** Automatic stock tracking, low-stock alerts for vendors.  
- **Vendor Management:** Admins can add vendors; customers can rate and review vendors.  
- **Customer Order Management:** Orders can be canceled or marked as delivered, with notifications.  

### 🔹 Mobile Application (Customer App)  
- **Browse & Search Products** by category.  
- **Place Orders & Track Status** from processing to delivery.  
- **Rate & Review Vendors** after order completion.  
- **Receive Notifications** on order updates.
